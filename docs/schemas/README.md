# Project schemas

The canonical, runtime-validated project schemas live in [`packages/contracts/schemas`](../../packages/contracts/schemas).

- `project.schema.json` describes the current format.
- `project-0.1.0.schema.json` is retained only for deterministic migration of early project documents.

The small `project.schema.json` file in this directory is a relative JSON Schema reference kept for documentation links that already target `docs/schemas`.
