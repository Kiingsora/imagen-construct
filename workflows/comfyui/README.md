# ComfyUI workflows

This directory will contain versioned workflow JSON files and adapter documentation.

Each workflow contribution must include:

- workflow id and version;
- required ComfyUI version;
- required custom nodes with exact sources;
- required models and licenses;
- expected inputs and outputs;
- tested hardware;
- sample request parameters;
- known failure cases;
- benchmark results.

Do not commit model weights or unreviewed custom-node archives.
